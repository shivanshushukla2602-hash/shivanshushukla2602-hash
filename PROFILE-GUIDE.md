The root README is the public GitHub profile. Its artwork lives in `assets/`.

The practice cards use v14 portrait canvases (540 × 750), keeping all three in
one row with an overall height comparable to the 1080 × 500 experiment panel.
Their GIFs and reduced-motion stills are generated by `practice_frame()` in
`scripts/motion_destinations.py`.

## Current motion graphics (v13)

Each destination now has a separate silhouette, material palette and motion
mechanism. The portfolio uses nested architectural frames with depth, opening
angles and a floating cursor. LeetCode uses a twisting amber ribbon; Codeforces
uses a blue Newton cradle with alternate outer pendulums; GeeksforGeeks uses a

facets. The experiment section is an iridescent sheet carrying travelling waves.

The original seated-developer scene remains a separate illustration below.

Run `npm run render:sections` or `python3 scripts/motion_destinations.py` after
installing `requirements.txt`; `--preview` renders static images only. The
renderer uses the canvas/projection helpers in `kinetic_sections.py` and button
helpers from `profile_destinations.py`, with fresh geometry and deformation code.
The eight GIFs use 60 samples at 100 ms each. The two wide scenes have dedicated
mobile layouts, and every animation has a static reduced-motion alternative.
Links, content scope and the activity-only daily refresh remain unchanged:
there are no project listings or coding totals in the profile.

## Previous project and problem-solving sections (v11)

## Edit content

- Change the introduction, links and project destinations in `README.md`.
- Change the original artwork and copy in `scripts/visuals.py`; `scripts/generate_design.py` writes the static artwork and animation frames.
- Run `python3 -m pip install -r requirements.txt` and `npm install`, then `npm run render` to rebuild the original vectors, animated header and articulated 3D studio. The 3D scene renderer starts its own local preview server. Set `CHROME_PATH` if Chrome is installed somewhere other than its normal macOS location.
- The GIFs are original vector-rendered animations. Each has a static fallback for reduced-motion preferences. These graphics do not depend on third-party stats-card services.

## Refresh public statistics

`Refresh public profile cards` runs once a day, or manually from the Actions tab.

- `scripts/update_activity.py` uses public GitHub repository data and the unauthenticated public contribution calendar. It never requests private contribution data.
- `scripts/update_coding.py` uses the supplied coding handles and accessible official public sources. Missing metrics remain absent; they are not presented as zero.
- `assets/activity-data.json` and `assets/coding-data.json` record the sources behind the cards.
- Generated GitHub language counts describe public repositories; they do not claim proficiency.
